# Freelance developer site

Static landing page for Mateusz Werpulewski's freelance software development services.

## Run locally

No build step or dependencies are required. Start any static file server from the repository root, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.
